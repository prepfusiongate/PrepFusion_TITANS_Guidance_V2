\section{How to Print PDFs Correctly}

\begin{alertbox}[\faPrint\enspace CRITICAL — Avoid Adobe Acrobat / Reader]
  \small
  \textbf{Do not use Adobe Acrobat or Adobe Reader to print out your course sheets or short notes.} Doing so can sometimes mess up formatting, margins, or corrupt layered graphic objects native to the export engine.\\[4pt]
  Always open and print your files directly through a web browser such as \textbf{Google Chrome}, \textbf{Microsoft Edge}, or \textbf{Mozilla Firefox} for perfect layout retention.
\end{alertbox}

\subsection{\faMobile\enspace Mobile PDF Modification \& Processing Workaround}

If you need to edit, clean up, or safely save your lecture notes using a mobile device before sending them for printing, use the following processing guide:

\begin{stepbox}[\faDesktop \enspace Processing Notes on Mobile]
  \small
  \begin{enumerate}
    \item \textbf{Install the App:} Download and install the verified utility app via the Google Play Store: \\
          \pflink{https://play.google.com/store/apps/details?id=com.cambyte.okenscan}{Play Store $\to$ OKEN Scanner App}
    \item\textbf{Can open the other app also: } Also you  can use the other scanner if it is compatible  that does the same job as this app is doing.
    \item \textbf{Open the Document:} Navigate to your downloaded study PDF file on your smartphone.
    \item \textbf{Importing:} Select the file and trigger the system prompt. Choose the option \textbf{"Save to OKEN Scanner"} / \textbf{"Open with OKEN Scanner"} from your system default list.
    \item \textbf{Save \& Clean Export:} Let the engine structure your document layers. Save the fresh copy from inside the application.
    \item \textbf{Share \& Print:} Use this newly optimized, cleanly exported PDF file to forward directly to your local printing setup.
    \item \textbf{Alternative Browser Workaround:} Open your PDF directly in \textbf{Google Chrome} and print from there; instruct your local print shop to do the same to ensure crisp, error-free outputs every time.
    
  \end{enumerate}
\end{stepbox}
